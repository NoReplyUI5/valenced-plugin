**Plugin Repo URL:** https://noreplyui5.github.io/valenced-plugin/

**Original Plugins**
- Age Gate Skip — Bypasses age-restricted channel confirmation prompts automatically.
- HypeSquad Switcher — Switch your HypeSquad house directly from settings.

**Ported Plugins:**
- Fast Copy User ID — Adds a "Copy User ID" button to the message action sheet to quickly copy the message author's ID.
- FavouriteAnything — Favourite any image or video, not just GIFs. Adds the favourite button to all media in the image viewer.

**Source Code:** [GitHub Repo](https://github.com/NoReplyUI5/valenced-plugin)

-# *All plugins tested on Discord Alpha `350.x` – `351.x`*
